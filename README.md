# NERVIA

Application web pour l'importation de gros dossiers.

## Fonctionnalités

- 📁 **Importation de dossiers volumineux** - Supporte les dossiers de toute taille
- 🖱️ **Glisser-déposer** - Interface intuitive avec drag & drop
- 📊 **Affichage détaillé** - Liste tous les fichiers avec leur taille
- 🚀 **Performance optimisée** - Gestion efficace des gros volumes de fichiers
- 📱 **Interface moderne** - Design responsive avec mode sombre

## Installation

```bash
npm install
```

## Développement

```bash
npm run dev
```

Ouvrez [http://localhost:3000](http://localhost:3000) dans votre navigateur.

## Build

```bash
npm run build
npm start
```

## Déploiement

Cette application est optimisée pour le déploiement sur Vercel.

## Utilisation

1. Visitez l'application
2. Glissez-déposez un dossier dans la zone prévue, ou cliquez sur "Sélectionner un Dossier"
3. L'application affichera tous les fichiers avec leur chemin et taille
4. La taille totale du dossier est calculée automatiquement

## Technologies

- Next.js 16
- React 19
- TypeScript
- Tailwind CSS
